## Agreements

1. **Commit prefixes:** `test:` (red), `feat:` (green), `refactor:`, `fix:`, `docs:`. One logical change per commit.
2. **No squash-merge.** Disabled in GitHub (Settings -> General -> Pull Requests) so the red-green-refactor trail survives. Use "Create a merge commit" or "Rebase and merge".
3. **`main` is branch-protected:** PR required, at least 1 approving review from a non-author, CI must be green before merge.
4. **Branch names:** `feature/<initials>-<topic>` for code, `docs/<initials>-<topic>` for documents.
5. **Reviewer rotation:** every PR is reviewed by a different member than its author (see the plan for who reviews what).
6. **AI usage:** every AI-assisted activity is logged in `docs/ai-usage-log.md` the same day; each member must be able to explain every line they submit.
7. **Secrets:** no admin token, password or key in source code. Admin token is read from `MAG_ADMIN_TOKEN` / `mag.admin.token`.
